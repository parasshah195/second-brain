# Security policy

## Supported versions

There are no released or supported production versions yet. The `develop`
branch is experimental; do not use it to store valuable or sensitive data.
Proof checking of domain rules is not a security audit of an application.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/parasshah195/second-brain/security/advisories/new).
Do not disclose exploits, credentials, or personal vault contents in public pull
requests or comments. If the reporting form is unavailable, contact the
maintainer privately using the contact details on their
[GitHub profile](https://github.com/parasshah195).

Include the affected commit/toolchain, a minimal synthetic reproduction,
expected behavior, and potential impact. No response-time SLA is promised
during early development. Reports will be triaged privately before coordinated
disclosure.
